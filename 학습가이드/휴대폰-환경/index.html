이 순서로 직접 해 보세요

  1. 과제의 기기 역할 정하기

    오늘 기기로 찾거나 들을 자료와 사용 후 할 행동을 적습니다. 검색이나 시청 자체를 전체 학습 완료로 삼지 않습니다.

  2. 한 장면 관찰하기

    과제 중 다른 화면으로 바뀐 시점과 이유를 짧게 남깁니다. 자세한 사적 메시지 내용보다 과제가 중단된 조건을 확인합니다.

  3. 약속 하나 바꾸기

    알림 조정, 자료 미리 열기, 필요한 확인 시간 정하기, 기기 위치 바꾸기 중 상황에 맞는 것을 고릅니다. 학생의 과제 접근과 가족 연락이 가능한 방법을 함께 정합니다.

  4. 수행 결과 비교하기

    비슷한 과제에서 중단, 완료 결과, 필요한 도움을 비교합니다. 휴대폰 사용이 줄어도 내용 이해가 불확실하면 별도의 학습 질문을 남깁니다.
