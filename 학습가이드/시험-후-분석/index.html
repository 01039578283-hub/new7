지금 상황부터 확인하세요

  • 시험 때 쓴 답안과 나중에 본 해설을 구분할 수 있나요? 실제 흔적이 없으면 기억에만 기대지 말고 확인 가능한 범위에서 분석합니다.
  • 시간이 부족했던 문제와 내용을 몰랐던 문제가 섞여 있나요? 둘 다 오답이어도 연습해야 할 행동은 다를 수 있습니다.

이 순서로 직접 해 보세요

  1. 문항 상태 나누기

    확실히 맞힘, 불확실하게 맞힘, 틀림, 시도 못 함으로 나눕니다. 점수와 함께 출제된 범위와 답안 요구를 확인하되 학교 시험의 일반 경향으로 확대하지 않습니다.

  2. 첫 어려움 찾기

    문제 읽기, 개념 선택, 풀이, 답안 표현, 시간 배분 중 처음 멈춘 곳을 표시합니다. ‘부주의’라고만 적지 말고 놓친 조건이나 잘못 쓴 줄을 구체적으로 남깁니다.

  3. 원인에 맞게 보완하기

    개념이 낯설면 설명과 기본 적용, 계산 오류면 해당 줄의 변형 이유, 근거가 부족하면 답안에 필요한 문장을 연습합니다. 시간 문제는 내용 이해를 확인한 뒤 풀이 순서와 중단 표시를 점검합니다.

  4. 새 자료에서 재확인하기

    해설을 읽은 문제의 정답 기억과 다른 조건에 적용한 결과를 나눕니다. 비슷한 과제에서 혼자 가능한지 확인하고 다음 학습 계획의 한 항목을 바꿉니다.

연습 예시: 수학 문제를 틀렸지만 계산은 정확했고 ‘정수’라는 조건을 읽지 않았다고 가정합니다. 오답노트에는 전체 해설 대신 놓친 조건과 답을 조건에 대입하는 확인 절차를 적습니다.

영어 문제는 맞혔어도 선택 이유가 ‘익숙한 표현이어서’라면 불확실한 정답으로 남깁니다. 다음에는 질문의 범위와 지문 근거를 적는 연습을 합니다. 같은 점수의 문항을 같은 원인으로 묶지 않습니다.
