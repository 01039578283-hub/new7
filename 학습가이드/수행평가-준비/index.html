지금 상황부터 확인하세요

  • 내용, 자료 수, 분량, 발표 시간, 제출 방식이 안내되어 있나요? 없는 조건을 임의로 만들지 말고 담당 선생님께 확인할 질문으로 남깁니다.
  • 조사한 자료와 자신의 설명이 섞여 있나요? 원문에서 가져온 사실, 직접 관찰한 결과, 본인의 해석을 구분할 수 있어야 합니다.

이 순서로 직접 해 보세요

  1. 안내의 동사 찾기

    ‘비교하라·설명하라·근거를 제시하라’ 같은 요구를 표시합니다. 평가 기준이 제공되면 각 요구 옆에 어떤 문장·표·자료로 답할지 적습니다.

  2. 작업을 나누기

    주제 정하기, 원자료 찾기, 초안 작성, 검토, 제출 확인으로 나눕니다. 마감 직전에 모두 끝내는 계획보다 선생님께 질문하고 수정할 여유를 남깁니다.

  3. 초안에서 연결 확인하기

    자료를 많이 붙였는지보다 자료가 어떤 주장에 필요한지 설명합니다. 읽기 자료의 표현 방식도 살펴보고, 초안에서 근거가 빠진 문장을 찾아 보완합니다.

  4. 제출 조건 확인하기

    내용 수정과 파일명·형식·업로드 확인을 분리합니다. 제출 버튼을 누른 후 학교가 안내한 완료 상태나 접수 화면을 확인하고 원본 파일을 보관합니다.

연습 예시로 살펴보기

예시의 다음 단계는 자신의 자료로

연습 예시: 두 지역의 교통 이용 자료를 비교하는 과제라면 ‘이용자 수가 다르다’만 쓰지 않습니다. 자료의 조사 연도, 조사 대상, 단위를 먼저 확인하고 공통 기준으로 비교할 수 있는지 적습니다.

초안에는 비교 기준과 관찰한 차이, 그 차이를 설명할 때 추가로 필요한 정보가 무엇인지 구분합니다. 보기 좋은 그래프를 만들었어도 기준 연도가 다르면 그대로 결론을 내리지 말고 비교의 한계를 표시합니다.

여기서 막히면 이렇게 조정하세요

주제를 못 정할 때

넓은 주제를 학교 요구에 맞는 하나의 질문으로 줄입니다. 자료를 실제로 찾을 수 있고 제출 분량 안에서 설명할 수 있는지 먼저 확인하세요.

조사만 하다 시간이 끝날 때

먼저 답할 질문과 필요한 자료 종류를 정합니다. 새 자료를 계속 모으기보다 확보한 자료로 초안을 쓰고 부족한 근거를 추가합니다.

보호자가 함께 도울 부분

초안을 대신 쓰거나 발표문을 완성해 주기보다 안내문을 읽고 빠진 요구를 묻습니다. 학생이 선택한 자료의 출처와 수정 이유를 설명하도록 돕고 작성 주도권은 학생에게 둡니다.
