지금 상황부터 확인하세요

  • 어떤 어려움을 해결하려고 도구를 쓰나요? 목적이 불분명하면 영상이나 답변을 계속 바꾸며 시간이 끝날 수 있습니다.
  • 학교의 도구 사용 안내와 서비스의 이용 조건을 확인했나요? 사용할 수 있는 범위와 자료 제출 조건을 먼저 읽습니다.

이 순서로 직접 해 보세요

  1. 작은 목표 정하기

    낯선 개념 하나, 문장 구조 하나, 풀이의 첫 판단처럼 필요한 것을 고릅니다. 강의 전체를 보는 일과 이해를 확인할 수행을 나누어 계획합니다.

  2. 설명 중 시도 남기기

    중요한 예제나 질문에서 잠시 멈춰 직접 설명하거나 풉니다. 이미 본 정답과 자신의 시도를 구분하고 필요한 부분만 다시 확인합니다.

  3. 답변의 근거 확인하기

    AI가 제시한 사실·숫자·출처는 교과서나 원문과 대조합니다. 출처가 실제로 존재하는지와 내용이 맞는지 확인하고 개인정보가 담긴 자료를 불필요하게 입력하지 않습니다.

  4. 도구 없이 적용하기

    창을 닫고 요약, 재풀이, 새 조건의 짧은 과제를 합니다. 도움의 범위와 남은 질문을 기록하고 다른 설명이나 선생님 확인이 필요한 부분을 구분합니다.

연습 예시로 살펴보기

예시의 다음 단계는 자신의 자료로

연습 예시: 분수 비교 영상을 본 뒤 영상을 닫고 같은 전체에서 1/3과 1/4의 크기를 설명합니다. AI에게 ‘답을 대신 쓰기보다 내 설명에서 빠진 조건을 질문해 달라’고 요청하는 방식도 생각할 수 있습니다.

AI의 확인이 맞다는 이유만으로 끝내지 말고 교과서의 정의와 그림으로 대조합니다. 다른 분수에서 혼자 설명한 결과를 남기고, 학교가 허용하지 않은 과제 대행에는 사용하지 않습니다. 요청 문장은 활용 연습용 예시입니다.

여기서 막히면 이렇게 조정하세요

강의를 많이 봐도 혼자 못 할 때

한 구간 뒤 직접 할 과제를 먼저 정합니다. 설명의 길이보다 실제로 막힌 단계를 확인하고 필요한 기초를 질문하세요.

AI 설명이 서로 다를 때

신뢰할 원문과 조건을 확인합니다. 표현이 자연스럽다는 이유로 사실을 선택하지 말고 확인되지 않은 부분은 남은 질문으로 남깁니다.

보호자가 함께 도울 부분

시청률이나 도구 사용 시간보다 직접 해 본 결과를 함께 봅니다. 어린 학생의 이용은 서비스 조건과 학교·가정의 안내를 확인하고 보호자가 필요한 도움을 제공합니다. 특정 도구의 이용 가능 연령을 임의로 단정하지 않습니다.

다음 과제에서 다시 점검하세요

비슷한 새 과제에서 설명 없이 가능한 범위를 확인합니다. 도구가 없으면 시작이 어려운 경우에는 첫 판단과 필요한 기초를 다시 점검하고 활용 범위를 고칩니다.
