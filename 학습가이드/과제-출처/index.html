이 순서로 직접 해 보세요

  1. 찾을 질문 구체화하기

    넓은 주제 대신 답할 질문과 필요한 자료 종류를 적습니다. 제도나 일정처럼 바뀌는 내용은 해당 기관의 현재 발표 자료를 확인합니다.

  2. 원문으로 이동하기

    게시 기관, 작성자, 발표일, 자료의 대상과 범위를 읽습니다. 다른 글이 인용한 통계라면 원래 조사 자료를 찾아 기준과 단위를 확인합니다.

  3. 사용 내용 나누기

    직접 가져온 표현, 자신의 말로 정리한 요약, 개인 의견을 구분합니다. 필요한 만큼 짧게 사용하고 학교의 출처·인용 안내를 확인합니다.

  4. 출처와 한계 남기기

    기관·제목·날짜·링크·확인한 위치를 적습니다. 서로 다른 자료가 말하는 범위가 다르면 차이를 설명하고 확인하지 못한 항목은 질문으로 남깁니다.
