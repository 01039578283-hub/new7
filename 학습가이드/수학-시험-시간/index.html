  • 연습 시간과 범위가 실제 시험 안내에 맞나요? 시험마다 달라지는 조건은 학교나 시험 주관기관의 현재 안내로 확인합니다.

이 순서로 직접 해 보세요

  1. 조건이 분명한 연습 고르기

    범위와 허용 시간, 자료 사용 여부를 적습니다. 먼저 작은 문제 묶음으로 현재 수행을 확인하고, 실제 시험 형식을 연습할 때는 해당 안내를 따릅니다.

  2. 시간과 중단 표시 남기기

    문제 시작과 이동 시점, 막힌 단계만 간단히 표시합니다. 기록 자체가 풀이를 방해하지 않도록 모든 생각을 실시간으로 적으려 하지 않습니다.

  3. 문항 상태 나누기

    읽기 어려움, 개념 선택, 계산, 검토, 미시도로 분류합니다. 마지막에 못 푼 문제도 이후 시간 제한 없이 시도해 내용과 시간의 원인을 구분합니다.

  4. 이동과 복귀 기준 연습하기

    진전 없이 머문 문제를 표시하고 다음 문제로 이동하는 방법을 시험해 봅니다. 무조건 같은 초 단위 기준을 적용하지 말고 문제 조건, 남은 시간과 자신의 수행을 보고 조정합니다.

연습 예시: 여섯 문제 중 두 번째에서 식을 못 골라 오래 머물고 마지막 문제는 읽지 못했다고 가정합니다. 마지막 문제를 나중에 혼자 풀 수 있었다면 두 문제의 원인을 같은 ‘어려움’으로 적지 않습니다.

두 번째는 조건 해석과 식 선택을 보완하고, 마지막은 앞 문항에서의 이동·복귀 연습을 확인합니다. 다음 작은 묶음에서는 오래 멈춘 단계와 미시도 수를 비교합니다. 예시 문제 수와 시간은 실제 안내에 맞춰 바꿉니다.

빠르게 풀면 정확도가 떨어질 때

반복 오류가 있는 계산이나 조건 검토를 유지합니다. 속도만 목표로 삼지 말고 독립 풀이의 정확성과 남은 검토 시간도 함께 봅니다.

보호자가 함께 도울 부분
